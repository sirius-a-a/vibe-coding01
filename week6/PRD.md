# 产品需求文档（PRD）- 企业人力成本分析系统

## 一、项目概述

| 项目项 | 内容 |
| --- | --- |
| 项目名称 | 企业人力成本分析系统 |
| 项目类型 | 前端 Web 应用（数据本地处理） |
| 目标用户 | HR、财务人员、企业管理者 |
| 核心价值 | 快速计算人力成本、生成个性化工资条 |

## 二、数据导入说明


## 三、功能需求

| 序号 | 功能 | 优先级 | 说明 |
| --- | --- | --- | --- |
| 1 | 员工成本计算 | P0 | 输入姓名 + 时间段，输出每月及总计的成本：税前工资（即工资条中的「所得合计」）、社保公司部分、公积金公司部分、经济补偿金。若某月份无该员工数据，则显示「无成本」 |
| 2 | 工资条批量输出 | P0 | 输入姓名 + 时间段，一次性输出该时间段内所有月份的工资条。若某月份无该员工数据，则显示「无工资条数据」 |
| 3 | 工资条字段隐藏 | P0 | 每个工资条可独立设置隐藏/显示任意字段，不同员工、不同月份的隐藏规则可不同 |
| 4 | 员工数据管理 | P1 | 支持导入/查看/编辑员工历史工资数据 |
| 5 | 成本趋势图表 | P2 | 可视化展示员工成本变化趋势 |

## 五、数据模型

### 5.1 员工工资记录

```javascript
{
    id: "uuid-xxx",
    name: "张三",
    year: 2026,
    month: 2,
    salary: {
        // 应发部分
        basicSalary: 10000,           // 基本工资
        positionAllowance: 2000,      // 岗位津贴
        dimissionDeduction: 0,        // 入离职扣款
        salaryChangeDeduction: 0,     // 工资变化扣款
        leaveDeduction: 0,            // 假期扣款
        otherPreTaxDeduction: 0,      // 其他税前扣款
        mealAllowance: 500,           // 餐补
        mealDeduction: 0,             // 餐补扣款
        computerAllowance: 200,       // 电脑补贴
        otherPreTaxIncome: 0,         // 其他税前应发
        overtimePay: 500,             // 加班费
        totalIncome: 13200,           // 所得合计（税前工资）
        
        // 扣款部分
        socialSecurityPersonal: 2500,  // 五险一金个人部分
        incomeTax: 500,               // 当月所得税
        compensation: 0,              // 经济补偿金
        otherAfterTaxDeduction: 0,    // 其他税后扣款
        
        // 实发
        netIncome: 10200,             // 净收入
        
        // 公司成本
        socialSecurityCompany: 1500,  // 社保公司部分
        housingFundCompany: 1200      // 公积金公司部分
    }
}
```

## 六、技术方案

| 模块 | 技术 | 说明 |
| --- | --- | --- |
| 结构 | HTML5 | 语义化标签 |
| 样式 | CSS3 | Flex/Grid 布局、响应式 |
| 交互 | JavaScript | DOM 操作、事件监听 |
| 数据处理 | 原生 JS | 数组/对象操作、日期处理 |
| 数据存储 | localStorage / IndexedDB | 存储员工工资数据和隐藏配置 |
| 数据导入 | File API | 支持 CSV/Excel 文件导入 |

## 七、验收标准

| 编号 | 验收项 | 通过标准 |
| --- | --- | --- |
| AC-01 | 成本计算-单月 | 输入姓名+单月，输出当月税前工资（即工资条中的「所得合计」）、社保公司部分、公积金公司部分、经济补偿金 |
| AC-02 | 成本计算-多个月 | 输入姓名+时间段，输出每月明细及各项的总和（税前工资、社保公司、公积金公司、经济补偿金） |
| AC-03 | 工资条-单月 | 输入姓名+单月，输出完整工资条 |
| AC-04 | 工资条-多个月 | 输入姓名+时间段，一次性输出多个月工资条 |
| AC-05 | 字段隐藏-单条 | 可对单个工资条设置隐藏特定字段 |
| AC-06 | 字段隐藏-独立 | 不同工资条的隐藏设置互不影响 |
| AC-07 | 响应式布局 | 手机/电脑都能正常使用，无横向滚动条 |
| AC-08 | 成本计算-缺失数据 | 查询的时间段内某月份无该员工数据时，该月份显示「无成本」，不影响其他月份正常显示 |
| AC-09 | 工资条-缺失数据 | 查询的时间段内某月份无该员工数据时，该月份显示「无工资条数据」，不影响其他月份正常显示 |
