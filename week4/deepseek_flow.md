# DeepSeek API 调用程序的数据流向图

以下是用 Mermaid 绘制的 4 张数据流向图，分别展示不同层次的数据流动。

---

## 图1：整体架构图

最精简的版本，只展示核心模块之间的数据流动。

```mermaid
flowchart LR
    A[用户输入] --> B[脚本处理]
    B --> C[DeepSeek API]
    C --> D[显示结果]
```

**节点说明**：
| 节点 | 作用 |
|------|------|
| A | 用户在终端输入问题或命令 |
| B | Python 脚本接收、处理、构造请求 |
| C | DeepSeek 云端服务器处理并返回回答 |
| D | 终端显示 AI 回答和统计信息 |

---

## 图2：用户交互与命令处理

只关注用户输入了什么，脚本如何响应。

```mermaid
flowchart TD
    A[启动脚本] --> B[显示欢迎界面]
    B --> C[等待用户输入]
    C --> D{输入类型}
    
    D -->|问题| E[进入API调用流程]
    D -->|clear| F[清空对话历史]
    D -->|save| G[保存历史到文件]
    D -->|history| H[显示历史摘要]
    D -->|quit| I[退出程序]
    
    F --> C
    G --> C
    H --> C
    E --> C
```

**节点说明**：
| 节点 | 作用 |
|------|------|
| A | 用户执行 `python api_fetch.py` |
| B | 显示帮助信息和提示 |
| C | 程序等待用户打字输入 |
| D | 判断用户输入的是问题还是命令 |
| E | 普通问题 → 调用 API |
| F/G/H | 各种命令 → 执行对应操作后返回等待 |
| I | 退出 → 结束程序 |

## 图3：API 调用与响应

只关注如何调用 DeepSeek API 和接收回答。

```mermaid
flowchart TD
    A[用户问题] --> B[添加到对话历史]
    B --> C[构造请求头]
    C --> D[构造请求体]
    D --> E[发送 POST 请求]
    
    E --> F[DeepSeek 服务器]
    F --> G{stream参数}
    
    G -->|true| H[流式响应<br>逐块返回]
    G -->|false| I[一次性响应<br>完整返回]
    
    H --> J[实时打印文字]
    I --> K[一次性显示回答]
    
    J --> L[保存到对话历史]
    K --> L
    L --> M[显示Token统计]
```

**节点说明**：
| 节点 | 作用 |
|------|------|
| A | 用户输入的问题文本 |
| B | 把问题加入 messages 列表 |
| C | 添加 Authorization 和 Content-Type |
| D | 添加 model、messages、stream 等参数 |
| E | 用 requests.post 发送 |
| F | DeepSeek 云端服务器 |
| G | 根据 stream 参数决定返回方式 |
| H/I | 两种不同的响应方式 |
| J/K | 两种不同的显示方式 |
| L | 把 AI 回答保存到历史 |
| M | 打印消耗的 token 数量 |

## 图4：错误处理与文件存储

只关注异常情况和数据保存。

```mermaid
flowchart TD
    A[API 请求] --> B{请求结果}
    
    B -->|成功| C[保存对话历史]
    C --> D[显示结果]
    D --> E[返回等待输入]
    
    B -->|失败| F{错误类型}
    
    F -->|网络超时| G[显示网络错误]
    F -->|连接失败| H[显示连接错误]
    F -->|认证失败| I[显示API Key错误]
    
    G --> J[移除当前问题]
    H --> J
    I --> J
    J --> E
```

**节点说明**：
| 节点 | 作用 |
|------|------|
| A | 向 DeepSeek 发送请求 |
| B | 判断请求成功还是失败 |
| C | 成功时自动保存对话到文件 |
| D | 正常显示 AI 回答 |
| E | 返回主循环，等待下一次输入 |
| F | 失败时判断具体错误类型 |
| G/H/I | 显示不同的错误提示 |
| J | 移除刚添加的问题（避免污染历史） |
